# 聖杯戦争TRPG キャラシメーカー（T6・IFGO） GitHub Pages 公開用

聖杯戦争TRPG（T6 PvP・IFGO）のキャラクターシート作成ツールです。
サーバー側の処理はありません。入力した内容は、開いた端末のブラウザ内（ホーム画面アプリの場合はそのアプリ内）にだけ自動保存されます。

このフォルダは、制作者（山吹）が自分の GitHub Pages で公開するためのものです。

## 公開のしかた（ブラウザだけでできます）

1. GitHub にログインし、右上の「＋」→「New repository」。
   - Repository name：好きな名前（例：`charasheet`）。これがURLの一部になります。
   - 「Public」を選んで「Create repository」。
2. 作成直後の画面の「uploading an existing file」をクリックし、このフォルダの中身（`index.html`・`manifest.webmanifest`・`sw.js`・`icons` フォルダ・`README.md`・`.nojekyll`）をまとめてドラッグ＆ドロップ →「Commit changes」。
   - フォルダごとではなく「中身」を入れます。リポジトリの一番上に `index.html` が来るようにしてください。
   - Mac の Finder では `.nojekyll` が隠しファイルで見えないことがあります。入れなくても動作に問題はありません。
3. リポジトリの「Settings」→ 左の「Pages」→「Build and deployment」の Source を「Deploy from a branch」、Branch を「main」「/(root)」にして「Save」。
4. 数分待つと、同じ画面の上部に公開URLが表示されます。
   - 形式：`https://（GitHubのユーザー名）.github.io/（リポジトリ名）/`

## iPhone での使い方

1. 公開URLを **Safari** で開きます。
2. 共有ボタン（□に↑）→「ホーム画面に追加」→「追加」。
3. 以後はホーム画面のアイコンから開いてください。
   - Safari のタブで使うと、しばらく開かなかったときにブラウザ側の判断で保存内容が消えることがあります。ホーム画面から開くアプリとして使えば、この削除の対象になりません。
   - ホーム画面アプリでの「JSON出力」「画像出力」は共有シートが開きます。「"ファイル"に保存」で保存できます。
   - 「JSON読込」は「ファイル」アプリから選べます。

> Safari のタブとホーム画面アプリ、別のURL（アーティファクト版・単体ファイル版など）では保存場所が別々です。
> 移すときは、移す元で「JSON出力」→ 移す先で「JSON読込」を使ってください。

## 更新のしかた

新しい版の公開用フォルダを受け取ったら、手順2と同じ画面（リポジトリのトップ →「Add file」→「Upload files」）で中身をすべてドラッグ＆ドロップし、「Commit changes」。
同じ名前のファイルは上書きされます。数分後、ネットにつながった状態で開くと新しい版になります（入力済みのシートはそのまま残ります）。

## 他の人に編集されないか

公開したサイトとリポジトリを書き換えられるのは、あなたのアカウント（と、あなたが Settings → Collaborators で招待した人）だけです。
他の人は中身を見ることはできますが、あなたのURLのツールを変えることはできません（改変・二次配布は利用規約で禁止しています）。
念のため、GitHub アカウントの二段階認証（Settings → Password and authentication）を設定しておくと安心です。

## ほかのキャラシツールと同じアカウントで公開する場合

同じ GitHub アカウントで別のキャラシツールも公開している場合は、**別のリポジトリ**に置いてください。このツールのブラウザ保存のキーとオフライン用のキャッシュ名は専用のものにしてあるので、同じ端末で使っても入力内容は混ざりません。
